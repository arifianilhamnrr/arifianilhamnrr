The special `arifianilhamnrr/arifianilhamnrr` profile README that renders on his GitHub profile. ## Operating Context

- Content is GitHub-flavored Markdown; GitHub sanitizes custom HTML/CSS, so expression comes from Markdown, code blocks, shields/badges, and third-party SVG widget services.
- A GitHub Action (`.github/workflows/snake.yml`) regenerates the contribution-snake SVG to the `output` branch on schedule, manual dispatch, and push to `main`.
- Rendered by third-party services: readme-typing-svg, skillicons.dev, github-readme-stats, github-readme-streak-stats, komarev profile views, img.shields.io.

## Capabilities and Constraints

- No custom HTML/CSS/JS execution; only sanitized Markdown + externally rendered images/SVGs.
- Visual coherence achieved by passing matching theme params (bg/accent/text colors) to every widget.
- Featured-projects repo names are UNDECIDED — must be supplied by the user before pin cards go live (broken repo names render error cards).

## Product Principles

- Show the developer, not a badge wall: lead with identity and real work.
- One coherent world: every widget shares the dark terminal palette and one accent.
- Make projects and collaboration the destination (showcase + open source are primary goals).
